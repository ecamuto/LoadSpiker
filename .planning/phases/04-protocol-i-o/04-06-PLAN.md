Replace the single-line return with:
```python
def tcp_connect(self, hostname: str, port: int, timeout_ms: int = 30000) -> Dict[str, Any]:
    result = self._engine.tcp_connect(hostname=hostname, port=port, timeout_ms=timeout_ms)
    if result.get('success') and result.get('tcp_data', {}).get('socket_fd', -1) >= 0:
        if not hasattr(self, '_tcp_connections'):
```
